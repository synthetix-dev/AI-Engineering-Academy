# Learning System & Pedagogical Design — AI Engineering Academy 2.0

## 1. Pedagogical Methodology

The learning architecture is structured to transition a learner from zero-programming intuition to senior AI engineering competence through guided interaction.

### 1.1. Dual Interaction Paradigm
- **Standard Mode (Visual & Intuitive)**: Sliders, interactive planes, drop-downs, visual cards, real-time reactive graphs. No requirement to write code to understand concepts.
- **Advanced Engineering Mode**: Toggleable on demand across all tools, exposing full hyperparameter dictionaries, PyTorch/scikit-learn parameters, and underlying JSON schemas.

### 1.2. The Universal "See How It Works" (Подивитися, як це працює) Action
Every interactive feature includes a dedicated inspection drawer exposing:
1. **Algorithm Name & Mathematical Intuition**: The formal formula and mathematical explanation.
2. **Library & Version**: The exact open-source library executing the logic (e.g. `scikit-learn 1.9.1`, `PyTorch 2.15.0`).
3. **Runtime Configuration**: The exact JSON hyperparameters passed to the model.
4. **Executable Code**: Python/TypeScript code matching the run.
5. **Sample Inputs & Outputs**: Real tensors and predicted labels.
6. **API Request**: The exact `cURL` request to replicate the calculation via REST API.
7. **Reproducible Script**: A terminal command to run the script standalone.

## 2. Personal Career Paths & Skill Graph

Upon registration, learners select one of 6 tailored career pathways:
1. **AI Engineer (Full-Stack AI)**: 12 priority tracks from data to agents and deployment.
2. **Machine Learning Engineer**: 10 priority tracks emphasizing mathematics, algorithms, and deep neural networks.
3. **LLM & Generative AI Engineer**: 10 priority tracks focusing on tokenization, RAG, LoRA, and autonomous tools.
4. **AI Researcher / Scientist**: 8 tracks focusing on optimization theory, Transformers, and ablation studies.
5. **AI Solutions Integrator**: 7 tracks focusing on REST APIs, Webhooks, MCP, and business workflows.
6. **Free Learning (Sandbox)**: Unrestricted self-paced exploration across all 20 tracks.

### Skill Graph DAG
Skills feature explicit prerequisites (e.g., `MATH_GRADIENTS` and `DATA_ENGINEERING` are required before `CLASSICAL_ML`, which in turn is required before `DEEP_LEARNING`). Skills are marked as verified only after passing automated, objective engineering evaluations.

## 3. Personal Cabinet

The student personal cabinet provides a distraction-free learning home:
1. **Продовжити навчання (Continue Learning)**: Quick resume button linking directly to the student's active track.
2. **Мій поточний AI-проєкт (My Active AI Project)**: Displays the student's living digital system, its version tag (e.g. `v1.2.0`), evolution level, and attached skills.
3. **Моя наступна навичка (My Next Skill)**: Graph-guided recommendation based on unlocked prerequisites.
4. **Збережені експерименти (Saved Experiments)**: History table of verified runs with real accuracy and loss metrics.
5. **Портфоліо (Portfolio)**: Direct access to shareable verified credentials.
